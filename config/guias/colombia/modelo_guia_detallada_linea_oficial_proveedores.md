# Modelo Guía Detallada Línea Oficial Proveedores

OBJETIVO
Establecer una guía detallada para la correcta gestión, atención y escalamiento de solicitudes relacionadas con proveedores dentro de la plataforma Dropi, garantizando el cumplimiento de los procesos logísticos, operativos y administrativos.
ALCANCE
Esta guía aplica para:
Proveedores.
Equipo logístico.
Soporte operativo.
Garantías.
Transportadoras.
Gestión de manifiestos.
Recolecciones.
Auditorías.
Seguridad y autenticación.
Gestión de productos y bodegas.
Incluye:
Creación y aprobación de productos.

Devoluciones.
Recolecciones fallidas.
DEFINICIONES
Proveedor: usuario que cuenta con inventario propio y permite que otros usuarios comercialicen sus productos dentro de Dropi.
Proveedor Verificado: proveedor que cumple con requisitos operativos y de calidad establecidos por la plataforma.
Proveedor Premium: proveedor con alto volumen operativo y cumplimiento avanzado de indicadores.
Ecom Scanner: aplicación utilizada para gestionar salidas, despachos y manifiestos.
Manifiesto: documento soporte del despacho realizado ante la transportadora.
Recolección fija: recolección automática diaria programada.
Recolección esporádica: solicitud puntual de recogida de paquetes.
OTP: código de seguridad utilizado para autenticación y validación de usuarios.
Privatización de productos: proceso mediante el cual un proveedor asigna productos exclusivos a un dropshipper.
