# Modelo Guía Detallada Triage

OBJETIVO
Establecer una guía detallada para la correcta gestión y atención de consultas, novedades, solicitudes y procesos relacionados con la operación de Dropi Colombia, permitiendo clasificar y direccionar adecuadamente cada caso según el área correspondiente.
ALCANCE
Esta guía aplica para el equipo de Triage, soporte, logística, garantías, retiros, compliance, anulaciones, desarrollo y proveedores de la plataforma Dropi Colombia.
Incluye:
Gestión de pedidos.
Validación de direcciones.
Garantías.
Configuración de cuentas.
Usuarios y permisos.
Procesos logísticos.
Transportadoras.
Wallet y retiros.
Dropi Card.
Facturación electrónica.
Gestión de proveedores y dropshippers.
DEFINICIONES
Dropshipper
Usuario que vende productos de terceros sin necesidad de manejar inventario propio.
Proveedor
Usuario que cuenta con inventario propio y permite que otros usuarios comercialicen sus productos.
Orden simple
Pedido que contiene un único producto sin variables.
Orden compuesta
Pedido con varios productos del mismo proveedor y misma bodega.
Orden de muestra
Pedido de prueba generado para validar un producto antes de comercializarlo.
Wallet
Billetera virtual de la plataforma donde se reflejan saldos, ganancias y movimientos.
Garantía
Proceso mediante el cual se reportan novedades relacionadas con productos entregados.
CAS
Sistema de gestión de novedades y escalamiento logístico.
Usuario logístico
Perfil con permisos operativos para despacho, inventario y generación de guías.
Usuario vendedor
Subusuario con permisos limitados para gestión comercial.
2FA
Autenticación de dos factores para protección de cuentas.

GUIA DETALLADA
5.1 REGISTRO Y TIPOS DE USUARIO
Registro incorrecto de perfil
Si el usuario se registra como proveedor/emprendedor, únicamente podrá visualizar sus propios productos y no tendrá acceso al módulo “Buscar productos”.
Venta en otro país
Los usuarios pueden operar en cualquier país donde Dropi tenga operación activa.
Cambio de país
No es posible modificar el país de una cuenta ya creada. Debe crearse una nueva cuenta.
¿Qué es Dropi?
Dropi es una plataforma tecnológica que integra procesos logísticos y de comercio electrónico para dropshippers, proveedores y emprendedores.

5.3 LOGÍSTICA Y TRANSPORTADORAS
Tiempos de entrega
3 a 5 días hábiles: ciudades principales.
5 a 8 días hábiles: ciudades secundarias.
Hasta 15 días hábiles: trayectos especiales.
Reexpedición
Indica que el envío va hacia trayecto especial.
Preferencias de transportadoras
Permiten priorizar transportadoras para generación automática de guías.
Homologación fallida
Una dirección con ícono rojo indica que Google Maps no logró validarla correctamente.
No es obligatorio cancelar la orden si la dirección fue validada con el cliente.
Interrapidísimo
No maneja novedades visibles en plataforma debido a telemercadeo interno.
CAS
Solo se habilita soporte cuando una guía lleva más de 48 horas sin movimiento.
Coberturas
Las coberturas logísticas pueden cambiar según condiciones de transportadoras.
