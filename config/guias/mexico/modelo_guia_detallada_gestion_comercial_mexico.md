# Modelo Guía Detallada Gestión Comercial México

OBJETIVO
Establecer los lineamientos para la gestión de solicitudes comerciales de la operación México, garantizando una atención homogénea y el correcto escalamiento de casos relacionados con anulaciones, despacho de órdenes, stock, envíos prioritarios, aprobación de productos y asignación de SIM.
ALCANCE
Aplica para los agentes encargados de gestionar solicitudes comerciales de la operación México.
Incluye:
Anulaciones.
Órdenes sin despacho.
Solicitudes de stock.
Solicitudes de envío prioritario.
Aprobación de productos.
Asignación de SIM.
DEFINICIONES
Anulación
Proceso mediante el cual se solicita cancelar una orden antes de su procesamiento o entrega.
Orden Pendiente
Pedido que aún no ha sido despachado por el proveedor y requiere seguimiento.
Stock
Cantidad disponible de un producto para su comercialización.
Envío Prioritario
Modalidad de gestión utilizada para priorizar el despacho de productos específicos o proveedores autorizados.
SIM
Tarjeta asignada dentro de procesos específicos gestionados por el equipo comercial.

5.2 ÓRDENES SIN DESPACHO, PENDIENTES O CON GUÍA GENERADA
Cuando un usuario solicite agilizar el despacho de una orden, se debe contactar al proveedor para recomendar que el despacho se realice lo antes posible.
Gestión administrativa
Sí el dropshipper solicita indemnización de una orden que no se ha despachado por más de 72 horas, se debe reportar por medio del espacio SAC México
5.3 SOLICITUD DE STOCK
Cuando un usuario solicite disponibilidad adicional de un producto, se debe solicitar el ID del producto y la cantidad requerida. Posteriormente, registrar la solicitud en el espacio de SAC México mediante una tarea asignada a David Jesus Carmona
5.4 SOLICITUD DE ID DE ENVÍO PRIORITARIO
Se debe validar el proveedor en la pestaña ENVÍOS PRIORITARIOS. Si no aparece en el listado, se deberá solicitar apoyo directamente al equipo comercial de México.
