# Modelo Guía Detallada SAC Panamá

OBJETIVO
Establecer los lineamientos para la atención, orientación, validación y escalamiento de solicitudes de los usuarios de la operación Panamá, garantizando una gestión homogénea, oportuna y alineada con los procedimientos definidos para cada área de soporte de la plataforma.
ALCANCE
Aplica para todos los agentes encargados de la atención SAC Panamá.
Incluye la gestión de:
Atención inicial de usuarios.
Escalamiento de solicitudes.
Logística.
Garantías.
Desarrollo.
Integraciones.
Gestión financiera.
Wallet.
Comunidades.
Cambio de correo.
Inactivación de cuentas.
Gestión de órdenes.
Gestión de productos.
Rastreo de envíos.
DEFINICIONES
Orden
Registro generado dentro de la plataforma que contiene la información comercial de una compra realizada por un usuario.
Guía
Documento logístico asignado a una orden para permitir el seguimiento del transporte y entrega del pedido.
Guía Sin Movimiento
Estado presentado cuando una guía no registra actualizaciones logísticas dentro del tiempo esperado y requiere validación adicional.
Wallet
Billetera virtual utilizada para administrar recargas, ganancias, retiros y movimientos financieros dentro de la plataforma.
OTP
Código temporal de seguridad utilizado para validar la identidad de un usuario durante procesos de autenticación.
Integración
Proceso de sincronización de información entre Dropi y plataformas externas.
Garantía
Proceso mediante el cual se reportan productos defectuosos, incompletos o que presentan fallas atribuibles al proveedor o fabricante.
Comunidad
Grupo de usuarios afiliados a programas especiales que otorgan beneficios adicionales dentro de la plataforma.
Cierre Logístico
Estado en el que una orden ya fue entregada por la transportadora y finalizó su proceso operativo.

MODALIDADES DE PAGO
La plataforma dispone de dos modalidades principales para la gestión de pagos de pedidos: Pago Contra Entrega y Pago Anticipado. Cada modalidad tiene implicaciones operativas y financieras diferentes.
PAGO CONTRA ENTREGA
En esta modalidad el cliente realiza el pago al momento de recibir el producto. Sin embargo, el costo inicial del envío es descontado temporalmente de la Wallet del usuario para cubrir la operación logística.
Flujo del proceso
Se genera la orden.
Se descuenta temporalmente el costo del envío.
La transportadora realiza la entrega.
El cliente paga al recibir el producto.
El valor correspondiente al envío es reintegrado.
Consideraciones
El intento de entrega genera costos operativos.
Las devoluciones no generan ganancias para el Dropshipper.
El reintegro depende de la entrega efectiva.
PAGO ANTICIPADO
En esta modalidad el cliente realiza el pago antes de que la orden sea procesada dentro de la plataforma.
Flujo del proceso
El cliente realiza el pago.
La orden es creada.
El pedido es procesado.
La orden es entregada.
El sistema distribuye automáticamente los valores correspondientes al proveedor.
Consideraciones
No es necesario realizar pagos directos al proveedor.
La liquidación ocurre una vez la orden alcanza estado Entregado.
